看一下上个月的目标:

- [ ] 完成之前的智能体项目,加入简单的RAG,最好能用docker部署.
- [ ] 重新学习C#,搞懂对应的网络框架和ORM框架
- [ ] 进一步学习算法,先完全解决应试,再深入工程问题中的算法
- [ ] 进一步学习数据库,学习Neo4j,Redis,MongoDB
- [ ] 再接触一下Go,尽量找到Go的闪光点
- [ ] 重新捡起python爬虫,整点新活儿,或许还可以用Go来做爬虫.
- [ ] 试着学习逆向工程,看看能不能做到AI翻译游戏.

可以说都是完成了一半的状态,唯一能够说基本完成的只有第一项和第二项了.一部分的原因在于放假之后的动力变小了,另一部分则是因为我也有了些许的迷茫.

毕竟,就算这么拼死拼活的学习,毕业之后又有什么有意思的工作呢,AI研发这块我是没兴趣的,但调API写智能体我肯定行;大厂的App开发早就到了尽头,就算工头心血来潮打算更换技术栈,那也只能顶上两三个月,之后又是无聊的运维环节,毕竟国内的用户增长已经到头了,而且头部App的用户都非常忠诚,在可见的十年内都不太可能有什么变故;至于网站开发,倒是有不少搞头,毕竟技术迭代的速度摆在那里,但未来的重心想必还是会逐渐偏向移动端的,毕竟能够静下心来浏览网页的人也越来越少了.唯一的存活方式只有WebView了.

不过,尽管如此,还有不少路可走,后端开发的需求只会增加而不会减少,因为内地的大公司都在逐渐向外扩张,尽管在国外的支持度不如欧美的国际公司,但依靠着低廉的劳动力和可怕的开发效率,想必也可以逐渐地吸引到越来越多的国际用户,毕竟国外的大多数app都是出了名的难用.

这样看来,起码我的程序员生涯还能苟延残喘个几十年,毕竟叫嚣了十年之久的元宇宙也不了了之了,而所谓的AGI还是卡在中途下不来也上不去,其实大公司也都知道这个局面,一旦有了突破性的架构诞生,研发成本和API调用成本一定会直线下降,这样一来,前面的所有努力都可以说是打了水漂,之前的deepseek-r1已经预示了一件事,一旦发现你并不值这么大的资金量投入,资本一定是会进行紧急避险的,到了那个时候,投入越狠的反而受创越大.

反过来看,微软,谷歌,苹果等国际大厂和国内的大多数大厂其实都很理智,没有真正的"ALL-in-AI",而那些以AI为借口来大幅度裁员的企业反而才是到了瓶颈期.君子不立于危墙之下,何况是见风使舵的资本呢.

分析了这么多,其实还是给自己一个安慰,希望自己当下所学能够为日后所用,否则这种苦修般的生活还是挺难坚持下去的.

制定一下8月份的计划:


- [ ] 学习完主流的后端工具链如Es,Kafka.
- [ ] 重新捡起爬虫,使用python,go,nodejs分别实现,感受效能差异
- [ ] 深入学习逆向工程,做到调用deepseek来翻译游戏脚本.
- [ ] 彻底研发出智能体应用,学习ts和python分别对应的测试框架使用,并放入智能体中.
- [ ] 深入学习rust,争取做到精通
- [ ] 捡起React Native,尝试开发一个app出来.
